# Bottom Log Panel

The bottom panel is inspired by development tools such as VS Code, while retaining Workbench's own visual identity.

Tabs:

- Logs
- Command
- Evidence
- Problems

Core interactions:

- open / close / collapse
- resize vertically
- select and copy arbitrary text
- copy selected / copy all
- search
- filter by severity/source
- raw / clean view
- save log
- export sanitized log
- choose previous operation log
- pause follow when user scrolls up
- resume follow with a clear new-lines indicator
