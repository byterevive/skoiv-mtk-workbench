# Tabs and Learn Workflow

Users should be able to learn and execute/inspect without losing context.

Example tabs:

```text
Overview | Learn: EMI | Inspect: preloader.bin | Backup #1
```

Requirements:

- Tabs preserve scroll position and local UI state.
- Learn content can open relevant tools in a new tab.
- Inspectors can open contextual Learn content.
- Safe Learn actions open in Command Studio for review; they do not auto-execute.
