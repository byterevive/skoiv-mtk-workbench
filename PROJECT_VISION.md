# Project Vision

Skoiv MTK Workbench is not intended to be a black-box flashing utility or merely a graphical wrapper around mtkclient.

The project aims to make MediaTek recovery work understandable, reproducible, safer, and accessible without requiring paid repair software.

## Core promise

For every meaningful conclusion or operation, the user should be able to answer:

1. What is the tool doing?
2. Why is it doing it?
3. What evidence supports the conclusion?
4. Which raw bytes, log lines, metadata, or device responses produced that evidence?
5. What can go wrong?
6. What backup protects the user?
7. How will success be verified?

## Community freedom

Skoiv MTK Workbench is intended to remain useful to people regardless of whether they can afford proprietary repair software.

The project therefore uses GNU GPL v3.0 so that users of covered distributed versions retain the freedom to study, modify, and redistribute the software and to obtain corresponding source as required by the license. Commercial use and paid services remain welcome; the project protects software freedom rather than requiring zero-cost services.

Third-party artifacts and dependencies retain their own licenses and are not automatically covered or redistributable merely because they are used with the Workbench.

## Long-term direction

The Workbench should grow from observation and backup into carefully controlled modification, guided recovery, community-tested compatibility knowledge, and reproducible research workflows.
