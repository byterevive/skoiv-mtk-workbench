# Contributing

Thank you for helping build Skoiv MTK Workbench.

## Before contributing

1. Read `PROJECT_VISION.md`.
2. Read `SAFETY_POLICY.md`.
3. Read `docs/adr/README.md` and applicable accepted ADRs.
4. Do not bypass documented safety boundaries for convenience.
5. Preserve raw evidence when adding parsers or abstractions.

## Architecture changes

A pull request that materially changes architecture, safety, compatibility, persistent formats, IPC, public interfaces, logging/evidence behavior, or contributor-facing conventions should include or reference an ADR.

## Licensing of contributions

Skoiv MTK Workbench is distributed under GNU GPL v3.0 only (`GPL-3.0-only`). Submit only contributions that you have the right to contribute under terms compatible with the project license.

Do not add third-party code, firmware, loaders, DAs, preloaders, documentation, media, or other artifacts unless their provenance and redistribution terms are understood and compatible with the repository policy. When in doubt, submit metadata, hashes, evidence, and an official source reference instead of redistributing a proprietary binary.
